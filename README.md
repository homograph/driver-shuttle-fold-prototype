# 셔틀 접기 프로토타입 · TADA-9317

‘수락 가능한 콜’ 목록에서 셔틀이 많아도 일반/묶음 콜에 바로 접근하게 하는 방식들을 비교하는 프로토타입.

**라이브(허브):** https://homograph.github.io/driver-shuttle-fold-prototype/

## 페이지
- **`index.html`** — 허브(메뉴). 세 방식으로 이동.
- **`hybrid.html`** ⭐추천 — 헤더탭 + 전체/셔틀 세그먼트. `전체`엔 대표 셔틀 1건 + ‘모두 보기’ + 묶음/일반(무한스크롤), `셔틀` 탭에 전체 200건(무한스크롤). 200건은 전체 스크롤에 안 섞임 → 페이지네이션·균형 동시 해결.
- **`ac.html`** — A/C 비교. 🅰️ 전용 화면 vs C 전체/셔틀 탭을 전환하며 페이지네이션 트리거 비교.
- **`inline.html`** — 초기안. 대표 셔틀 + ‘모두 보기’ 인라인 펼침.

각 프로토타입 상단 `← 방식 목록`으로 허브 복귀.

## 공통 원칙
**셔틀 200건 전체는 일반 리스트와 한 스크롤을 공유하지 않는다.** (무한스크롤 두 개를 한 스크롤에 쌓지 않음)

## 눌러볼 것
