# 셔틀 접기 프로토타입 · TADA-9317

‘수락 가능한 콜’ 목록에서 **셔틀을 하나의 그룹(대표 콜 + “모두 보기” 버튼)** 으로 묶어, 셔틀이 많아도 일반/묶음 콜에 바로 접근하게 하는 인터랙티브 프로토타입입니다.

## 보기
`index.html`을 브라우저로 열면 됩니다. (단일 파일, 외부 의존성 없음)

## 확정 방향
- **대표 셔틀은 진짜 콜 카드**로 노출 → 그 아래 **“셔틀 N건 더 있어요 · 모두 보기”** 버튼이 붙어 한 그룹으로 읽힘.
- 고령자·sp 글씨 확대 대응: 은유(스택·작은 화살표) 대신 **문구 + 큰 버튼**, 가로 스크롤 없음.
- 화면 순서: `필터/정렬(최상단) → 셔틀 그룹 → 묶음 → 일반`. 셔틀 그룹은 항상 최상단 고정.

## 프로토타입에서 눌러볼 것
- **모두 보기 / 접기** — 셔틀 그룹 펼침·접힘
- **정렬** — 추천순 / 시간 임박순 / 배수 높은 순 (셔틀 최상단 고정, 아래만 재정렬)
- **↻ 새로고침** — 전체 재조회 스피너, 접힘/펼침 상태 유지
- 상단 컨트롤: **시나리오**(정상 9건 / 셔틀 1건 / 0건 / 권한 없음 / 셔틀 실패), **글씨 크기**(기본 / 크게)
