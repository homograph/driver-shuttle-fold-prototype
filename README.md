# 셔틀 접기 프로토타입 · TADA-9317

‘수락 가능한 콜’ 목록에서 셔틀이 많아도 일반/묶음 콜에 바로 접근하게 하는 프로토타입.

## 화면
- **`index.html`** — 🅰️ **전용 화면** vs C **전체/셔틀 탭** 비교 (셔틀 200건·무한스크롤 페이지네이션 테스트). 상단 ‘방식’ 버튼으로 전환.
- **`inline.html`** — (참고) 초기 확정안: 대표 셔틀 콜 + ‘모두 보기’ 인라인 펼침.

라이브: https://homograph.github.io/driver-shuttle-fold-prototype/

## 방식 비교 (index.html)
| | 🅰️ 전용 화면 | C 전체/셔틀 탭 |
|---|---|---|
| 셔틀 인지 | 메인에 대표 셔틀 1건 상시 노출 | 탭 배지 `셔틀 200` |
| 셔틀 전체 보기 | ‘모두 보기 →’ 전용 화면 진입 | ‘셔틀’ 탭 전환 |
| 더 불러오기 | 메인=묶음/일반, 셔틀화면=셔틀 (다른 화면) | 전체탭=묶음/일반, 셔틀탭=셔틀 (다른 탭) |
| 일반 접근성 | 대표 1건이 위에 얹힘 | 전체 탭은 100% 일반 |

두 방식 모두 **무한스크롤 두 개를 한 스크롤에 쌓지 않는다**는 원칙으로 페이지네이션 트리거 모호성을 해결.

## 눌러볼 것
- 방식 전환(🅰️/C) · 정렬(추천/임박/배수) · 새로고침 · 글씨 크기(sp)
- **스크롤 최하단 → “더 불러오는 중” → 다음 페이지 append** (무한스크롤)
